Kéo để xoay

Tôi làm cho dữ liệu chạy đúng chỗ, đúng lúc.

Phần lớn công việc của tôi nằm phía sau màn hình: thiết kế API, hiện thực nghiệp vụ ERP từ bán hàng đến kế toán, và xây pipeline đưa dữ liệu từ nhiều nguồn vào data warehouse để phục vụ báo cáo.

AI là một phần trong cách tôi làm việc: phân tích yêu cầu, sinh code, hỗ trợ debug, viết tài liệu và tự động hoá luồng dữ liệu lặp lại. Thời gian tiết kiệm được dành cho thiết kế và tối ưu hệ thống.

DataController.cs
public async Task<IActionResult> GetDataAsync(int id)
{
    var result = await _service.GetByIdAsync(id);
    return Ok(result);
}

Bốn mảng tôi làm sâu nhất

Mỗi mảng đi kèm sơ đồ kiến trúc tôi thường áp dụng trong dự án thực tế.

Data warehouse và pipeline

ETL/ELT và đồng bộ dữ liệu qua các tầng Staging, Integration, Core, Marts. Xây dựng với SSIS, SSAS, SSRS và Power BI.

Phát triển có AI hỗ trợ

AI agent dùng công cụ và bộ nhớ để sinh code, hỗ trợ debug, viết tài liệu và tự động hoá luồng dữ liệu.

Ứng dụng web và API

ASP.NET Core Web API theo kiến trúc microservices: API gateway, xác thực, cache và dịch vụ thông báo.

Hệ thống ERP
